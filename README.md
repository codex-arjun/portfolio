# 🚀 Portfolio Website – Arjun Sharma

This is my personal *Portfolio Website* built using *React.js* and *Tailwind CSS*, showcasing my work, skills, and contact details.  
The portfolio highlights my expertise as a *Full Stack Developer* with real-world projects, experience, and professional background.

---

## 📌 Features
- 🎨 Modern responsive design with *Tailwind CSS*
- 👨‍💻 Hero section with profile and quick links (Resume, LinkedIn, GitHub)
- 📝 About Me section with bio and skills overview
- 📊 Skills with animated progress bars
- 💼 Services section describing my offerings
- 📂 My Work / Projects section (with GitHub links & descriptions)
- 📞 Contact section with form + social media links
- 🌐 Deployable on *GitHub Pages / Netlify / Vercel*

---

## 🛠 Tech Stack
- *Frontend:* React.js (JSX, Functional Components, Hooks)  
- *Styling:* Tailwind CSS  
- *Deployment Options:* GitHub Pages / Netlify / Vercel  

---
